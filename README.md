### 🧬 7대 기준 유사도 프로파일 & 선발 알고리즘
- **평가 7개 지표 (각 1/7 ≈ 14.3% 균등 가중치)**:
  1. `지역 (Region)`: 국가 및 세부 산지 테루아 일치도 (14.3%)
  2. `농장 (Farm)`: 농장/스테이션명 토큰 정규화 일치도 (14.3%)
  3. `프로듀서 (Producer)`: 농장주/가문 일치도 (14.3%)
  4. `컵노트 (Cup Notes)`: 38개 센서리 어휘 토큰 기반 Jaccard 유사도 (14.3%)
  5. `프로세스 (Process)`: 워시드/허니/내추럴/무산소 발효 매칭도 (14.3%)
  6. `배전도 (Roast Profile)`: 드립/필터 라이트로스트 일치도 (14.3%)
  7. `고도 (Altitude)`: 재배 해발고도 차이 구간별 유사도 (14.3%)
- **핵심 판정 룰**:
  - **프로파일 중복 여부는 점수 산정 기준에 절대 포함하지 않고**, 순수 점수로 1~20위를 매깁니다.
  - **동일 농장 예외 규칙**: 동일 농장/프로듀서이더라도 **컵노트가 다르면 중복 제외하지 않고 실질 추천(Active Pick)으로 선발**합니다.
    - *예시: 4위 `Ethiopia Elto Sama Honey`(살구/복숭아/멜론 꿀)는 1위 `Sama Washed`(얼그레이/자스민/배)와 컵노트 자카드 유사도가 0%로 완전히 달라 당당히 Pick #3으로 최종 선발.*
  - 상위 순위 원두와 향미/테루아가 겹치는 하위 10종은 시각적 **음영(Dimmed) 처리**하여 구매 시 중복을 방지합니다.

### 🛒 장바구니 및 현지 구매 발주서 연동 시스템
1. **표 좌측 체크박스**: 기본으로 엄선 10선이 체크되어 있으며, 개별 선택/해제 및 전체 선택 가능.
2. **실시간 견적 계산 툴바**: 표 상단 및 하단에 선택된 원두 개수, 총 결제 금액(AED) 및 원화 환산액(KRW)이 실시간 연동.
3. **독립 발주서 ([`cart.html`](cart.html) / [`mobile_cart.html`](mobile_cart.html))**:
   - `[장바구니 보기 ↗]` 클릭 시 선택된 원두들을 담아 독립된 공식 발주서로 즉시 이동.
   - 각 원두 이름 클릭 시 **해당 로스터리 공식 웹스토어로 바로 연결**되어 현지에서 즉시 결제 가능.
   - **👥 장바구니 공동 편집 링크 복사**: 동료와 장바구니를 함께 수정할 수 있는 링크를 생성. 전달받은 동료가 품목을 추가/삭제/변경한 후 다시 링크를 생성하여 변경사항을 상호 동기화.
   - **🔒 발주서 불변 링크 확정 복사 (동결 스냅샷)**:
     - 발주 확정 시점의 문서 번호(PO-XXXX), 확정 일시, 원두 목록, 가격 데이터를 **영구 동결(Frozen)**하는 Base64 암호화 링크(`?snapshot=...`) 생성.
     - **핵심 보장**: 이후 다른 사람이 장바구니를 어떻게 수정하더라도, **구매 담당자에게 전달된 불변 링크는 생성 시점의 내용 그대로 절대 변경되지 않고 완벽히 보존**됩니다. 수정/삭제 버튼이 잠기고 확정 문서로 박제됩니다.
   - **현지 구매 담당자 인수인계 최적화**: 구매 체크리스트, A4 인쇄/PDF 저장(`window.print()`), 카카오톡/슬랙용 텍스트 발주서 원클릭 복사 탑재.
